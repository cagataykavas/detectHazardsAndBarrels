# Security and responsible use

Report vulnerabilities privately through GitHub's security advisory workflow. Include
the affected version, reproduction, and likely impact.

The application makes no network requests and processes inputs locally. Input and
annotated videos may contain sensitive incident details or identifiable people; review
and redact artifacts before sharing.

This project is not a certified safety system. Do not use it as the sole basis for
emergency response, evacuation, material handling, surveillance, or decisions about
people. Treat every result as advisory and require qualified human verification.
